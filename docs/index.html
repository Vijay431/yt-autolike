Auto-Like Modes

🌐 Global

The default mode — set it and forget it! 🙌 YT AutoLike will automatically like both regular YouTube videos and Shorts once you've hit your watch threshold. Perfect if you just want everything handled without thinking about it.

⚡ Only Shorts

A Shorts-only lane! 🎬 Auto-likes kick in exclusively on YouTube Shorts — those quick vertical videos you binge through. Great if you love supporting short-form creators but prefer to manually like longer videos yourself.

🎞️ Only Videos

For the long-form lovers. 📺 Only standard YouTube videos (not Shorts) will get the auto-like treatment. Ideal if you're super selective about Shorts but want to automatically support the channels you actually sit down and watch.

✅ Whitelist Only

Your VIP list. 🌟 Auto-likes happen only for channels you've explicitly approved. Everyone else? No automatic like. Perfect if you want laser-precise control — only your favourite creators get the love, automatically.

Manual Installation Guide

Use this guide when a marketplace listing is not available for your browser yet. Manual installs depend on files you keep locally, so treat the downloaded package and extracted folder as part of the installation.

🌐

Chrome / Chromium

  1. Download the Chrome ZIP ↗ or Chromium ZIP ↗.
  2. Move the ZIP to a permanent folder — don't delete it later or the extension will break.
  3. Extract the ZIP inside that folder.
  4. Open chrome://extensions/ in your browser.
  5. Toggle on Developer mode (top-right switch).
  6. Click Load unpacked and select the extracted folder.
🦊

Firefox

  1. Download the Firefox ZIP ↗.
  2. Move the ZIP to a permanent folder — Firefox needs it there to stay installed.
  3. Open about:debugging#/runtime/this-firefox in Firefox.
  4. Click Load Temporary Add-on…
  5. Select the ZIP file you downloaded.
🌊

Microsoft Edge

  1. Download the Edge ZIP ↗.
  2. Move the ZIP to a permanent folder — don't delete it later or the extension will break.
  3. Extract the ZIP inside that folder.
  4. Open edge://extensions/ in Edge.
  5. Toggle on Developer mode (left sidebar).
  6. Click Load unpacked and select the extracted folder.
