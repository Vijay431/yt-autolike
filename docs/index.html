Manual Installation

Browser marketplace listings are still being prepared. Until the store pages are live, use the latest release ZIPs and manual installation steps below.

🌐

Chrome / Chromium

  1. Download the Chrome ZIP or Chromium ZIP.
  2. Extract the downloaded ZIP.
  3. Go to chrome://extensions/.
  4. Enable Developer mode.
  5. Click Load unpacked and select the extracted folder.
🦊

Firefox

  1. Download the Firefox ZIP.
  2. Go to about:debugging#/runtime/this-firefox.
  3. Click Load Temporary Add-on...
  4. Select the downloaded zip file.
🌊

Microsoft Edge

  1. Download the Edge ZIP and extract it.
  2. Go to edge://extensions/.
  3. Enable Developer mode.
  4. Click Load unpacked and select the folder.
