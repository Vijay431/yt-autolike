# Acknowledgements

YT AutoLike stands on a thoughtful stack of open-source libraries, tooling, and release helpers.
Thank you to the maintainers who make privacy-first browser extension work easier, faster, and more
reliable.

## Application Libraries

- **React** and **React DOM** power the extension UI.
- **TypeScript** keeps the codebase safer and easier to maintain.
- **Extension.js** provides the browser-extension development and build workflow.
- **canvas-confetti** adds lightweight celebratory UI moments.
- **Framer Motion** supports polished interaction and motion.
- **Lucide React** provides clean, consistent interface icons.

## Testing and Quality

- **Testing Library** helps verify the UI through user-centered tests.
- **Vitest** powers fast unit and integration test runs.
- **Playwright** supports browser-level validation across extension flows.

## Package and Release Tooling

- **pnpm** keeps dependency installs reproducible and efficient.
- **Prettier**, **ESLint**, and **TypeScript** help keep the project consistent.
- The packaging and release scripts in `scripts/` prepare browser-specific builds, runtime ZIPs,
  source archives, package validation, and Chrome Web Store upload support.

Thank you as well to every person who reports issues, shares accessibility feedback, suggests
improvements, tests on different browsers, or helps make the project easier to use in more languages.
